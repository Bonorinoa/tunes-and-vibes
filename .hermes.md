# Tunes and Vibes — Hermes project rules

n=1 panel: WHO-5 + Spotify + Garmin. Repo is the source of truth.

## Runtime
- Python: `./.venv/bin/python` (never system 3.9).
- Tests: `./.venv/bin/python -m unittest discover -s tests -v`
- Secrets only in `.env` (gitignored). Do not print client secrets or tokens.
- Cron lives on the **default** Hermes profile (`tv-ingest`, `tv-digest`, `tv-who5`). Do not duplicate those jobs into another profile.

## Invariants
- Missing data is a row status, never a crash.
- Do not overwrite a `collected` wellness row with a transient `api_error`.
- ReccoBeats catalog misses persist on `tracks.not_found`; do not retry them.
- No daily self-report. WHO-5 is weekly, Sunday, questions before numbers.
- Passive metrics are not emotions (`garmin_raw`, `reccobeats_derived`).
- Scratch one-offs stay in `scratch/` (gitignored). Do not promote them into `src/`.
